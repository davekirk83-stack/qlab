onward, with no newer file published, rule (c) makes it unreadable and rule (a)
escalates an unreadable level to EXIT: pb_halt active=1, flatten=1, every open
paper position closed with reason 'halt', all fourteen books blocked 14 days.

unrefreshed file rather than by anything the market did, and it would put a

One action prevents it: the investing side publishes a new file in
PA Operation > 01 Capital named `CRASH ALERT — <LEVEL> — <YYYY-MM-DD>` at any
level, including a restatement of AMBER. That resets the clock. Flagged in docs
195 and 196 and in the 3, 8 and 25 Oct reporting logs.

Docs 195 and 196 both predicted the flatten would happen on this run. The
difference is the hours: at 07:25 UTC the file had not yet crossed. A run fired
later in the day would have read it the other way.
